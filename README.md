# にせそにっく 🦔

ソニック風の非公式ファンメイド2Dアクションゲームです。

## 🎮 プレイする

https://ferrarissound-design.github.io/nisesonik/

スマートフォンでは横画面推奨。画面下の◀▶で移動、Aでジャンプ、▼でローリング。停止中に▼を押しながらAを連打して、▼を離すとスピンダッシュ。

PCでは←→またはA/Dで移動、Space/Zでジャンプ、↓/Sでローリング、Pでポーズ、Mでミュート。

GitHub Pagesへの公開は `.github/workflows/pages.yml` で自動実行されます。GitHubリポジトリの Settings → Pages で Source を GitHub Actions に設定してください（未設定の場合）。

※セガ公式作品ではありません。ファンメイド作品です。
